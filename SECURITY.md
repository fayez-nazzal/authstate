# Security

## Supported versions

Only the latest release of `authstate` is supported.

## Reporting a vulnerability

- Do not open a public issue.
- Use GitHub private vulnerability reporting at `https://github.com/fayez-nazzal/authstate/security/advisories/new`.
- Include the `version` field from the JSON output, your OS and the steps to reproduce.
- You get a first reply within seven days.

`authstate` handles live passwords and session jars. Treat any leak of a jar or a credentials file as urgent. Change the password and sign the account out everywhere.
